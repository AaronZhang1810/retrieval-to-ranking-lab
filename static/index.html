α is selected on validation users from a configuration-declared 0–0.10 grid. Contributions describe this linear score; they are not causal explanations.

MovieLens records use numbered user IDs; that is not a guarantee of anonymity. Ratings are selectively observed, so an unjudged movie is unknown—not a dislike. This local trace exposes held-out labels for auditing only; aggregate claims belong in REPORT.md.
